# EmailPro - Agence d'Emailing

Bienvenue sur le site web de notre agence d'emailing professionnelle. Nous sommes spécialisés dans la création et la gestion de campagnes email marketing performantes qui génèrent des résultats mesurables.

## 🚀 Fonctionnalités

- **Site Web Responsive** : Design adaptatif pour tous les appareils (desktop, tablette, mobile)
- **Section Services** : Présentation complète de nos services d'email marketing
- **Formulaire de Contact** : Système de contact interactif pour les prospects
- **Animations Fluides** : Transitions et animations pour une expérience utilisateur agréable
- **Navigation Moderne** : Menu de navigation fixe avec défilement fluide

## 📋 Services Proposés

1. **Campagnes Email** - Création et gestion de campagnes personnalisées
2. **Analytics & Reporting** - Suivi détaillé des performances
3. **Design & Templates** - Création de templates responsive et attractifs
4. **Segmentation** - Ciblage précis de votre audience
5. **Automation** - Automatisation des campagnes
6. **Optimisation** - Tests A/B et amélioration continue

## 🛠️ Technologies Utilisées

- HTML5
- CSS3 (avec variables CSS et animations)
- JavaScript Vanilla (ES6+)
- Design Responsive (Mobile-First)

## 📂 Structure du Projet

```
Emailing/
```

## 🚀 Démarrage Rapide

1. Clonez le repository
2. Ouvrez `index.html` dans votre navigateur
3. C'est tout ! Aucune installation ou compilation nécessaire

## 💻 Utilisation

Le site est une application web statique qui fonctionne directement dans le navigateur. Vous pouvez :

- Naviguer entre les différentes sections via le menu
- Remplir le formulaire de contact
- Consulter les services proposés
- Voir les statistiques de l'agence

## 📱 Compatibilité

- ✅ Chrome (dernière version)
- ✅ Firefox (dernière version)
- ✅ Safari (dernière version)
- ✅ Edge (dernière version)
- ✅ Responsive sur mobile et tablette

## 🎨 Personnalisation

Pour personnaliser le site :

1. **Couleurs** : Modifiez les variables CSS dans `css/style.css` (section `:root`)
2. **Contenu** : Éditez directement le fichier `index.html`
3. **Fonctionnalités** : Ajoutez ou modifiez les fonctions dans `js/script.js`
