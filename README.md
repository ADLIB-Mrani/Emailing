## 🎨 Personnalisation

Tous les projets sont facilement personnalisables :

### Modifier les Couleurs
Dans le fichier CSS, changez les variables :
```css
:root {
    --primary-color: #2563eb;  /* Votre couleur principale */
    --secondary-color: #1e40af; /* Votre couleur secondaire */
}
```

### Modifier les Textes
Dans le fichier HTML, changez simplement le contenu des balises.

### Modifier les Statistiques
Dans le fichier JavaScript :
```javascript
const STATS_TARGETS = {
    clients: 500,        // Votre nombre de clients
    emails: 10000000,    // Vos emails envoyés
    satisfaction: 95     // Votre taux de satisfaction
};
```
