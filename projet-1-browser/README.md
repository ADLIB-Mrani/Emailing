# Projet 1 : Agence d'Emailing (100% Navigateur - Sans Téléchargement)

## 🌐 Description
Ce projet est une solution **entièrement basée sur le navigateur** qui ne nécessite **aucun téléchargement** ni installation. Tout fonctionne directement dans votre navigateur web.

## ✨ Caractéristiques
- ✅ **Aucun téléchargement requis**
- ✅ Fonctionne directement dans le navigateur
- ✅ Utilise des outils en ligne gratuits
- ✅ Modification en temps réel
- ✅ Partage facile via URL

## 🚀 Comment l'utiliser

### Option 1 : CodePen (Recommandé)
1. Allez sur [CodePen.io](https://codepen.io/)
2. Créez un compte gratuit (optionnel)
3. Cliquez sur "Create" → "Pen"
4. Copiez le code fourni dans les sections correspondantes

### Option 2 : JSFiddle
1. Allez sur [JSFiddle.net](https://jsfiddle.net/)
2. Collez le code dans les panneaux HTML, CSS et JavaScript
3. Cliquez sur "Run" pour voir le résultat

### Option 3 : CodeSandbox
1. Allez sur [CodeSandbox.io](https://codesandbox.io/)
2. Créez un nouveau "Vanilla" project
3. Remplacez le contenu avec notre code
