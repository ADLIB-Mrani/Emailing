## 🎯 Options d'Hébergement Gratuit

### Option 1 : GitHub Pages (⭐ Recommandé)

**Avantages :**
- Hébergement gratuit illimité
- SSL automatique (HTTPS)
- Nom de domaine : `votre-nom.github.io`
- Très rapide et fiable
- Déploiement automatique

**Instructions :**

1. **Créer un compte GitHub** (si vous n'en avez pas)
   - Allez sur https://github.com/
   - Cliquez sur "Sign up" (Inscription)
   - C'est 100% gratuit !

2. **Créer un nouveau repository**
   - Cliquez sur le bouton vert "New" ou "+"
   - Nommez votre repository : `agence-emailing`
   - Cochez "Public"
   - Cliquez sur "Create repository"

3. **Uploader les fichiers**
   - Cliquez sur "uploading an existing file"
   - Glissez-déposez tous les fichiers de ce dossier
   - Cliquez sur "Commit changes"

4. **Activer GitHub Pages**
   - Allez dans "Settings" (Paramètres)
   - Cliquez sur "Pages" dans le menu de gauche
   - Sous "Source", sélectionnez "main" branch
   - Cliquez sur "Save"

5. **Votre site est en ligne !**
   - URL : `https://votre-nom.github.io/agence-emailing/`
   - Le déploiement prend 2-3 minutes

### Option 2 : Netlify

**Avantages :**
- Déploiement en glisser-déposer
- SSL gratuit
- Nom de domaine : `votre-site.netlify.app`
- Interface très simple
- Mises à jour instantanées

**Instructions :**

1. **Créer un compte Netlify**
   - Allez sur https://netlify.com/
   - Cliquez sur "Sign up" avec GitHub ou email
   - 100% gratuit !

2. **Déployer votre site**
   - Cliquez sur "Add new site" → "Deploy manually"
   - Glissez-déposez le dossier complet
   - Votre site est en ligne en 10 secondes !

3. **Personnaliser le nom**
   - Cliquez sur "Site settings"
   - Changez le nom du site
   - Ex: `agence-emailing.netlify.app`

### Option 3 : Vercel

**Avantages :**
- Performance excellente
- SSL gratuit
- Nom de domaine : `votre-site.vercel.app`
- Analytics gratuits
- Prévisualisation des modifications

**Instructions :**

1. **Créer un compte Vercel**
   - Allez sur https://vercel.com/
   - Cliquez sur "Sign up" avec GitHub
   - Gratuit pour usage personnel !

2. **Importer le projet**
   - Cliquez sur "Add New" → "Project"
   - Importez depuis GitHub ou uploadez les fichiers
   - Cliquez sur "Deploy"

3. **Votre site est en ligne !**
   - URL : `https://votre-projet.vercel.app`

### Option 4 : Render

**Avantages :**
- Services statiques gratuits
- SSL automatique
- Nom de domaine : `votre-site.onrender.com`
- Build automatique

**Instructions :**

1. **Créer un compte Render**
   - Allez sur https://render.com/
   - Inscription gratuite

2. **Créer un Static Site**
   - "New" → "Static Site"
   - Connectez votre repository GitHub
   - Deploy automatique !
