## 💰 PROJET 2 : Hébergement Gratuit

### ✨ En Bref
Site web complet hébergé gratuitement avec une vraie URL publique.

### 👍 Avantages
- ✅ 100% gratuit
- ✅ URL publique (ex: mon-site.netlify.app)
- ✅ HTTPS inclus (sécurisé)
- ✅ Rapide à déployer
- ✅ Facile à mettre à jour

### 👎 Inconvénients
- ⚠️ Nécessite un compte (gratuit)
- ⚠️ Nom de domaine avec extension .netlify.app

### 🚀 Démarrage Express
```
1. Allez sur app.netlify.com/drop
2. Glissez-déposez le dossier projet-2-gratuit/
3. Votre site est en ligne !
```

### 📍 Quand L'Utiliser ?
- Pour un vrai site public
- Pour votre portfolio
- Pour montrer à des clients
- Pour apprendre le déploiement

➡️ [Voir la Documentation Complète](projet-2-gratuit/README.md)
